The method defines the detectable chemical domain

Hollender et al. (2023), Fig. 2, “NORMAN guidance on suspect and non-target screening in environmental monitoring,” Environmental Sciences Europe. CC BY 4.0. Publication · License.

Design preparation around the question

The method’s chemical domain is not known in advance: it is the overlap of extraction, chromatography and ionisation. Characterise that domain with representative reference compounds.

Generic NTS preparation

Favor broad coverage and limited processing to minimise losses. For water, use direct injection when sensitivity allows; enrich by SPE when needed. Extract solids with broad solvent mixtures.

Add selective cleanup only when needed

It can reduce interferences and improve sensitivity, but may narrow the compound domain or lose analytes. Check suitability with representative standards for priority chemical groups.

Quality checks: field, laboratory and procedural blanks reveal contamination; reference compounds and spiked-matrix samples test method coverage and performance.

But how usable are these tools in practice?

DreaMS — a foundation model for MS/MS spectra

  • Self-supervised pre-training on GeMS — 700M unannotated MS/MS spectra mined from GNPS — no library needed.
  • Transformer architecture learns molecular representations by predicting masked peaks and retention order.
  • Fine-tuning transfers to spectral similarity, fingerprint prediction, chemical properties, and fluorine detection.
  • DreaMS Atlas — a molecular network of 201M MS/MS spectra built with DreaMS embeddings.
Bushuiev et al., Nat Biotechnol 2026

FBMN — Feature-Based Molecular Networking

  • 1. Acquire — LC-MS/MS separates, ionizes, and fragments molecules, generating features and MS/MS spectra per sample.
  • 2. Detect features — MZmine, OpenMS, XCMS, or MS-DIAL produce a feature table and MGF spectral file.
  • 3. Build the network — Feature-Based Molecular Networking (FBMN) on Global Natural Products Social Molecular Networking (GNPS) links spectra by cosine similarity; related molecules cluster into molecular families.
  • 4. Extend with IIN — Ion Identity Networking adds edges for adducts, dimers, and multimers, reducing redundancy and clarifying topology.
Nothias et al., Nat Methods 2020
Wang et al., Nat Biotechnol 2016
Try it →

From MS/MS fragments to a molecular fingerprint

  • The idea: an MS/MS spectrum is a set of fragments that carries clues about a molecule’s substructures.
  • Molecular fingerprint: a compact vector of predicted substructure bits — a machine-readable summary, not a complete structure.
  • SIRIUS + CSI:FingerID: SIRIUS uses the fragmentation pattern to infer a formula and fragmentation tree; CSI:FingerID predicts the fingerprint, then ranks database candidates that best match it.
Dührkop et al., PNAS 2015

project <- MassSpecEngine$new(
  metadata = list(
    name = "Example project",

  Method_NonTargetAnalysis_FindFeatures(),

  Method_NonTargetAnalysis_LoadFeaturesMS2()

project$run()

What is MCP (Model Context Protocol)?

UUserdescribes a request
→
✦AI agentplans a solution
→
MMCP serveroffers discoverable tools
→
▣Connected toolreturns data
JSON-RPC message (Remote Procedure Call) that the AI agent sends to the MCP server.
{
  "method": "tools/call",
  "params": {
    "name": "list_operations",
    "arguments": {
      "domain": "mass_spec",
      "module": "chromatograms"
    }
  }
}

How does the AI agent discover tools in the MCP server?

The server advertises its tools and the agent discovers them instead of hard-coding.
✦AI agentstarts a connection
→
MMCP serverloads available tools
→
☷tools/listreturns names and schemas
→
✓AI agentselects and calls a tool
The tool list gives the agent descriptions and input schemas.
{
  "tools": [
    { "name": "list_operations",
      "description": "List operations available in a domain and module",
      "inputSchema": {
        "type": "object",
        "properties": {
          "domain": { "type": "string" },
          "module": { "type": "string" }
        },
        "required": ["domain", "module"]
      } }
  ]
}
