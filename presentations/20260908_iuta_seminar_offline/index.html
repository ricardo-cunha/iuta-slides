What is vibe coding?

Vibe coding is an AI agent working with you through a chat.

  • Chat: lets you describe the task and review the response.
  • LLM: understands your instructions and generates code.
  • Harness: gives the model tools to work with files and programs on the host.
  • AI agent: combines these pieces to inspect files, make changes, and test the result.
You > Summarize the measurements
Agent > I will inspect the data
Host > read_file measurements.csv
Agent > I will create the summary in script.py
Host > create file script.py
Agent > send "run script.py" to Host
Host > run script.py
Agent > show the result in chat

What is MCP (Model Context Protocol)?

UUser“How many samples are in batch_list.csv?”
→
✦AI agentunderstands the request and plans a possible solution
→
MMCP serveroffers tools the agent can discover
→
▣Connected toolreturns batch_list.csv content for the agent to inspect
JSON-RPC message (Remote Procedure Call) that the AI agent sends to the MCP server.
{
  "method": "tools/call",
  "params": {
    "name": "read_file",
    "arguments": { "path": "batch_list.csv" }
  }
}

How the AI agent discovers tools in the MCP server?

The key idea is that the server advertises its tools and the agent discovers them instead of hard-coding.
✦AI agentstarts a connection
→
MMCP serverloads the tools it can provide
→
☷tools/listreturns names, descriptions, and schemas
→
✓AI agentselects a tool based on user request or context and calls it
JSON-RPC message is the MCP exchange with the AI agent after the tool list call, containing descriptions and schemas.
An ontology can add shared knowledge to help the agent understand what each tool does.
{
  "tools": [
    "...",
    {
      "name": "read_file",
      "description": "Read a text file",
      "inputSchema": {
        "type": "object",
        "properties": { "path": { "type": "string" } },
        "required": ["path"]
      }
    },
    "..."
  ]
}

Take-home message

  • Vibe coding alone is not enough for FAIR analytical data processing: code needs explicit semantics, validation, and provenance.
  • An ontology standardizes meaning through harmonized definitions and knowledge-network graphs.
  • MCP gives AI agents controlled tools, reducing token-heavy instructions and constraining operations.
  • Ontology enriches MCP tools with semantic context, enabling more informed tool discovery and use.
  • streamfind is in active development, with ontology and MCP development at its core.
One semantic foundation can make analytical work reproducible, reusable, and AI-accessible.
