R scripting interface

library(StreamFind)

project <- MassSpecEngine$new(
  metadata = list(
    name = "Example project",
    author = "Ricardo Cunha"
  )
)

workflow <- Workflow(list(
  Method_NonTargetAnalysis_FindFeatures(),
  Method_NonTargetAnalysis_LoadFeaturesMS1(),
  Method_NonTargetAnalysis_LoadFeaturesMS2()
))

project$Workflow <- workflow
project$run()

What is MCP (Model Context Protocol)?

UUserdescribes a request
→
✦AI agentplans a solution
→
MMCP serveroffers discoverable tools
→
▣Connected toolreturns data
JSON-RPC message sent by the AI agent to the MCP server.
{ "method": "tools/call", "params": { "name": "read_file", "arguments": { "path": "batch_list.csv" } } }

How does the AI agent discover tools in the MCP server?

The server advertises its tools and the agent discovers them instead of hard-coding.
✦AI agentstarts a connection
→
MMCP serverloads available tools
→
☷tools/listreturns names and schemas
→
✓AI agentselects and calls a tool
The tool list gives the agent descriptions and input schemas.
{ "tools": [{ "name": "read_file", "description": "Read a text file", "inputSchema": { "type": "object" } }] }
